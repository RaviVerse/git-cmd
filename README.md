# Git Command Matrix

A modern, interactive Git command reference designed to help developers work faster with Git and GitHub.

## Features

* Copy ready Git commands
* Complete first time GitHub setup guide
* SSH authentication workflow
* Initial repository upload process
* Daily Git workflow commands
* Branch management shortcuts
* Remote repository operations
* Undo and recovery commands
* Repository inspection tools
* Clean, developer focused interface

## What You'll Find

### SSH Setup

Generate SSH keys, configure authentication, add keys to GitHub, and verify connections.

### Initial Upload Workflow

Step by step commands to initialize a repository, connect it to GitHub, create commits, and push code.

### Daily Development Workflow

Quick commands for:

* Add and commit changes
* Push updates
* Pull latest changes
* Fetch remote updates

### Branch Management

Common branch creation, switching, merging, and cleanup commands.

### Remote Operations

Manage origins, update remotes, and synchronize repositories.

### Undo & Recovery

Safely revert changes, restore files, and recover previous states.

### Repository Inspection

View history, track changes, inspect branches, and monitor repository status.

## Purpose

Git Command Matrix serves as a fast reference tool for developers who want practical Git commands without searching through documentation. Every command is organized for quick access and everyday use.

## Tech Stack

* HTML
* CSS
* JavaScript

## Usage

Open the application in your browser and use the categorized command sections to quickly find, copy, and execute Git commands.
